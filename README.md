# Job Search Website

A responsive and user-friendly Job Search Website developed using HTML, CSS, JavaScript, Bootstrap, and related frontend technologies. The website provides an attractive interface for job seekers to explore opportunities, view services, and connect with employers.

## 🚀 Features

- Responsive and modern UI design
- Home, About, Services, Pricing, Blog, and Contact pages
- Interactive navigation menu
- Bootstrap-based layout
- Mobile-friendly design
- Smooth animations and transitions
- Clean and organized project structure

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- jQuery
- Font Awesome
- Owl Carousel
- WOW.js

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/anjanareddy01/Job-Search.git
```

2. Navigate to the project folder:

```bash
cd Job-Search
```

3. Open `index.html` in your browser.
